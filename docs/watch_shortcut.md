# Команда iPhone «FitBud ⌚»: данные Apple Watch → бот

Команда берёт данные из приложения «Здоровье» за последние 2 дня и отправляет их боту.
Повторная отправка ничего не задваивает — сервер перезаписывает день целиком.

Собирается **один раз** на iPhone (≈20–30 минут), потом раздаётся ссылкой iCloud.
Названия типов в «Командах» могут немного отличаться от написанных здесь — ищи по первым буквам.

---

## 0. Ключ

Бот: **👤 Мой профиль → ⌚ Часы Apple Watch → 🔑 Получить ключ**. Скопируй ключ.

## 1. Начало команды

1. «Команды» → **＋** → назови команду **FitBud ⌚**.
2. Добавь действие **«Текст»** и вставь в него ключ. Это первое действие команды.

## 2. Данные: по одному действию «Найти данные Здоровья» на показатель

Для каждой строки таблицы добавь действие **«Найти данные Здоровья»** и настрой:
- **Тип** — из таблицы;
- **Начало** → **«в последн. 2 дней»**;
- **Единица** и **Единица группирования** — из таблицы.

Быстрее всего: настроить первое действие, затем долго нажать на него → **«Дублировать»** и поменять тип.

| Ключ | Тип в «Здоровье» | Единица | Группирование |
|---|---|---|---|
| `steps_w` | Шаги + фильтр «Источник» → Apple Watch | шт. | **Час** |
| `steps_p` | Шаги + фильтр «Источник» → iPhone | шт. | **Час** |
| `active_kcal_w` | Активная энергия + «Источник» → Apple Watch | ккал | **Час** |
| `active_kcal_p` | Активная энергия + «Источник» → iPhone | ккал | **Час** |
| `distance_w` | Расстояние ходьбы и бега + «Источник» → Apple Watch | км | **Час** |
| `distance_p` | Расстояние ходьбы и бега + «Источник» → iPhone | км | **Час** |
| `exercise_min` | Время упражнений | мин | День |
| `resting_hr` | Пульс в покое | уд./мин | День |
| `hrv` | Вариабельность пульса | мс | День |
| `sleep` | Анализ сна / Сон | — | **Нет** |
| `workout` | Тренировки | — | **Нет** |

Дополнительно, если хочется больше данных (необязательно, можно добавить позже):

| Ключ | Тип | Единица | Группирование |
|---|---|---|---|
| `resting_kcal` | Энергия покоя | ккал | День |
| `flights` | Пройдено пролётов | шт. | День |
| `walking_hr` | Средний пульс при ходьбе | уд./мин | День |
| `spo2` | Кислород в крови | % | День |
| `resp_rate` | Частота дыхания | вдох/мин | День |
| `wrist_temp` | Температура запястья во сне | °C | День |
| `weight` | Вес | кг | День |
| `body_fat` | Процент жира | % | День |
| `vo2max` | Кардиофитнес (VO₂ max) | — | День |

Если какого-то типа нет в списке — просто пропусти его.

**Почему шаги, калории и дистанция — двумя блоками по часам.** Если ходишь и с часами, и с телефоном,
оба считают одни и те же шаги. «Здоровье» не складывает их, а «Команды» складывают. Поэтому команда
отправляет данные часов и iPhone отдельно по каждому часу, а сервер берёт за каждый час большее —
как «Здоровье». Шаги, пройденные без часов, тоже засчитываются.

## 3. Отправка

Добавь действие **«Получить содержимое URL»**:
- **URL:** `https://fitbud.rentadevops.ru/health/v1/sync`
- **Метод:** POST
- **Заголовки:** добавить заголовок `X-FitBud-Key` → значение: переменная **«Текст»** (ключ из шага 1)
- **Тело запроса:** JSON. Для каждого показателя добавь поля типа **«Текст»**:

| Поле | Значение (переменная → свойство) |
|---|---|
| `<ключ>_d` | «Данные Здоровья» этого показателя → **Дата начала**, формат **ISO 8601** |
| `<ключ>_v` | та же переменная → **Значение** |

Например, для шагов: `steps_d` и `steps_v`.

Как выбрать свойство: в поле значения нажми **«Выбрать переменную»** → выбери нужное действие
«Данные Здоровья» → нажми на появившуюся переменную → **Дата начала** (там же выбрать **Формат даты → ISO 8601**,
включить время) или **Значение**.

Для **сна** — три поля:

| Поле | Значение |
|---|---|
| `sleep_d` | Дата начала, ISO 8601 |
| `sleep_e` | Дата окончания, ISO 8601 |
| `sleep_v` | Значение (фаза сна) |

Для **тренировок** — сколько получится из доступных свойств:

| Поле | Значение |
|---|---|
| `workout_d` | Дата начала, ISO 8601 |
| `workout_e` | Дата окончания, ISO 8601 |
| `workout_t` | Тип тренировки (или название) |
| `workout_kcal` | Активная энергия тренировки, ккал |
| `workout_km` | Дистанция, км |
| `workout_hr` | Средний пульс |

Обязательные для тренировки — только `workout_d`, `workout_e`, `workout_t`, остальное по возможности.

## 4. Ответ сервера (по желанию)

После «Получить содержимое URL» добавь **«Получить значение из словаря»** (ключ `message`)
и **«Показать уведомление»** с этим значением. Будет видно «Получено показателей: 12».

## 5. Проверка

Нажми ▶️. Первый раз iPhone спросит доступ к «Здоровью» — разреши **все** типы.
В боте должно прийти «⌚ Тренировка с часов…» (если была), а в «📋 Мой день» — кнопка **«⌚ Данные с часов»**.

Сверь шаги с приложением «Здоровье». Если в боте больше (iPhone и часы посчитали дважды) —
в действии «Шаги» добавь фильтр **«Источник» → твои Apple Watch**.

## 6. Автоматизация

«Команды» → **Автоматизация** → **＋**:
1. **Приложение** → Telegram → **«Открыто»** → **«Выполнять сразу»** → действие «Запустить команду» → FitBud ⌚.
   Главный способ: на заблокированном iPhone данные «Здоровья» недоступны, а при открытии Telegram он точно разблокирован.
2. **Время суток** → 13:00, 18:00, 22:00 (три автоматизации) → **«Выполнять сразу»** → FitBud ⌚.

## 7. Поделиться командой

⚠️ **Сначала убери свой ключ**: иначе все, кто поставит команду, будут отправлять данные в твой дневник.

1. Открой команду → настройки команды → **«Вопросы при импорте»** → добавь вопрос для действия «Текст»
   («Вставь ключ из бота FitBud»), а сам текст ключа сотри.
2. **Поделиться → Скопировать ссылку iCloud.**
3. Ссылку — разработчику: она будет показываться в боте при подключении часов
   (переменная `HEALTH_SHORTCUT_URL` в `docker-compose.override.yml`).
